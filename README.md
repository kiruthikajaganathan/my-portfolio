# Kiruthika J - Portfolio

A professional portfolio website built with HTML, CSS, and JavaScript.

## Features

- **Responsive Design** - Works on desktop, tablet, and mobile devices
- **Modern UI** - Clean, professional design with gradient accents
- **Smooth Animations** - Scroll animations and interactive elements
- **All Sections Included**:
  - Hero section with profile photo and contact info
  - About Me section
  - Technical Skills
  - Key Projects
  - Work Experience
  - Education
  - Certifications
  - Achievements
  - Contact section

## How to Use

1. **Add your profile photo**: Place your professional headshot as `profile.jpg` in the same directory as `index.html`. If no photo is found, a placeholder will be displayed.

2. **Update social links**: In `index.html`, update the LinkedIn and GitHub links in the hero and contact sections:
   ```html
   <a href="YOUR_LINKEDIN_URL" class="social-link"><i class="fab fa-linkedin"></i></a>
   <a href="YOUR_GITHUB_URL" class="social-link"><i class="fab fa-github"></i></a>
   ```

3. **Open the portfolio**: Simply open `index.html` in your web browser. No server required!

## Customization

### Colors
Edit the CSS variables in `styles.css` to change the color scheme:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --dark-color: #1e293b;
    --light-color: #f8fafc;
    --text-color: #334155;
    --text-light: #64748b;
    --accent-color: #06b6d4;
    --gradient: linear-gradient(135deg, #6366f1 0%, #8b5cf6 100%);
}
```
